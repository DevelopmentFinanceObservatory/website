# Prototypes

Small tools built on the [Development Finance Observatory](https://developmentfinance.org/)'s data, one a day during the build week of 16 to 20 November 2026. Each one fetches its data once with the DFO SDKs and ships as a static page.

## Built from the site's parts

These pages use the site's fonts, colours and components directly, so a prototype looks like the rest of the Observatory.
